# Trim a PR description

Keep the intent, user-visible change, important implementation detail, Jira or issue link, and verification status. Remove repeated context, process narration, and low-value bullets. Aim for roughly 70% of the original length when that can be done without losing a decision or caveat. Return the revised text without editing or posting it unless asked.
