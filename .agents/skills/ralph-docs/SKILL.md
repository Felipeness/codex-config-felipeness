# Iterative documentation

Find the source of truth, identify the documentation gap, and update only the relevant pages. Check commands, paths, and examples against the repository. Stop when the requested audience can follow the workflow and the claims match the implementation, or after six meaningful iterations. Do not run commands or publish docs externally unless asked.
