# Figma Code Connect

- Identify the exact Figma component and the implementation component used by the repository. Do not guess mappings from similar names.
- Follow the installed Code Connect package version and existing `.figma.*` examples.
- Map meaningful props, variants, and slots to the real component API. Keep examples compilable and representative.
- Use connected Figma tooling when available. If access or identifiers are missing, request them before writing a speculative mapping.
- Validate the mapping with the repository's documented Code Connect command only when verification is requested or part of the task.
