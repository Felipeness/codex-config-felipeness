# Investigate

- Establish the current state from files, configuration, history, and available runtime evidence before forming a theory.
- Find the relevant entry points, dependencies, constraints, and existing conventions. Prefer targeted searches and reads over broad dumps.
- Separate verified facts, likely explanations, and unknowns. Ask only for information that blocks a useful next step; continue independent discovery meanwhile.
- Present a concise summary of the problem, evidence, open risks, and viable next steps. Do not implement unless asked.
