# Iterative performance work

Start from a user-provided target or establish a baseline if measurement is requested. Locate the bottleneck before optimizing. Change one relevant factor at a time and compare against the same workload. Stop when the target is met, the measured bottleneck is removed, or six meaningful passes produce no useful gain. Avoid speculative micro-optimization and report measurement limits.
