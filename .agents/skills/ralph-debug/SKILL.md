# Iterative debugging

Use `$debugging` to reproduce the symptom, trace the first incorrect state, and form a testable hypothesis. Change one cause at a time and inspect the result. Stop when the issue is resolved, after six meaningful iterations, or when required evidence is unavailable. Add or run tests only when requested or required by the acceptance criteria.
